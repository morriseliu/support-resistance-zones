# 支撑压力区扫描（Support / Resistance Zones）

只画支撑 / 压力区，不打分、不给概率、不给买卖信号。

## 规则摘要（冻结规格 v1.0，见 `SPEC_FROZEN_20261122.md`）

- 摆动点：某根 K 线的最高价（或最低价）是前后各 5 根里最高（或最低）的那根。
- 区：不是精准单价线，是一组摆动点 `[最低价, 最高价]`；区宽 ≤ 触碰时 ATR(14) 的 1.0 倍；一个区至少 2 次触碰，且两次间隔 ≥ 5 个交易日；单次触碰不成区，不画。
- 破区只看收盘价越过区沿：支撑区收盘价低于区下沿才算破，压力区收盘价高于区上沿才算破；盘中刺破、收盘回到区内不算破。中间被收盘越过的摆动点按破区点切开、分别计数。
- 靠近：收盘价在区内距离为 0；离区沿 ≤3% 为“靠近”。收盘价已穿区沿的单独标注“已穿区”。
- 每只票最近支撑 / 压力各最多 3 个区；回看 500 个交易日；日线周线各自算，周线同价标注“日周同价”。翻转区（原支撑跌破后在头顶、原压力涨破后在脚下）单独标注。
- 基准日：**2026-11-20 收盘**（首份快照）。之后每日刷新时基准日顺延为最新交易日，规则不变。

## 范围

- 美股：全美市值前 300 只普通股（Nasdaq screener marketCap 排名，不含 ETF/优先股/权证）。
- A 股：沪深主板 + 创业板，剔除科创板（688 开头）、ST/*ST、总市值 < 50 亿元、收盘价 < 5 元、停牌/无成交；北交所不进。

## 数据来源

- 美股：Nasdaq screener（universe 与市值）、Yahoo Finance 日 K 线。
- A 股：腾讯快照（universe、价、总市值）、新浪日 K 线。

## 网站

GitHub Pages：`docs/` 目录为网站源文件，`docs/data/` 为已核验的发布快照（`manifest.json` 含快照日期、生成时间与校验状态）。网站分两个分区：

1. **支压位统计**：分 A 股 / 美股，列全部扫描到的票，点票可见 K 线 + 区色带图。
2. **危险区**：分支撑危险区 / 压力危险区，只列收盘价在区内或离区沿 ≤3% 的票。危险区是位置提示，不是买卖信号。

首页常驻快照日期、生成时间、校验状态；快照超 2 个交易日未更新显示过期提示。数据请求加时间戳参数，避免浏览器缓存。

## 刷新

`.github/workflows/refresh.yml`：每天北京时间工作日约 06:00（美股与 A 股都收盘后）自动运行，也可手动触发（Actions 页 → Run workflow）。每次刷新先跑校验关（快照日 = 两市最新交易日、抽查票收盘价与源站一致、成功率不异常低于上次）：校验不过不提交新快照、保留旧快照。

## 文件

- `engine.py` — 区计算引擎（输入 OHLCV，输出各区）。
- `scan_us.py` / `scan_a.py` — 美股 / A 股扫描脚本（可复用，支持 `--date` / `--auto-date`）。
- `scripts/validate_snapshot.py` — 发布前校验关；`scripts/publish_snapshot.py` — 仅校验通过时发布快照。
- `SPEC_FROZEN_20261122.md` — 冻结规格（改参数即新版本）。
- `SCAN_REPORT_20261120.md` — 首份扫描校验报告。
- `a_universe_codes.txt` — A 股 universe 代码清单（供每日刷新重过滤用）。
